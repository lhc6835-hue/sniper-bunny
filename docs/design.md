# Sniper Bunny — 디자인 브리프

## 플레이어 약속
공중을 날아다니는 토끼 저격수가 슬로모션 속에서 로봇의 머리를 날려버린다.

## 핵심 루프
플레이어는 **점프·플립으로 기동하며 스나이퍼/단검으로** 로봇 웨이브를 **처치**한다.
로봇의 **레이저 사격과 근접 돌진**이 압박을 만들고, 성공하면 **점수·콤보·포커스(슬로모션 게이지)**를 얻고,
실패하면 체력을 잃고 사망 시 즉시 재시작한다.

- 5~30초마다 반복: 점프 → 공중에서 우클릭 조준(슬로모) → 헤드샷 → 볼트 당김 → 다음 타겟
- 1~5분 동안 변화: 웨이브마다 적 수 증가, 원거리 로봇 비율 증가, 속도 상승
- 잘하는 플레이어: 포커스를 아껴 쓰고, 근접 로봇은 단검 대쉬로, 원거리 로봇은 헤드샷으로 정리, 공중 킬 보너스

## 조작
| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| Space | 일반 점프 (지상) |
| Shift | 하이 플립 점프 — 위+앞으로 도약하며 앞구르기 회전. 지상 1회 + 공중 2회 |
| 우클릭 (홀드) | 스코프 조준 + 슬로모션 (포커스 소모) |
| 좌클릭 | 스나이퍼 발사 (볼트액션, 히트스캔) |
| F (홀드 → 놓기) | 홀드: 슬로모션 + 단검 차징 + 타겟 락온 / 놓기: 락온한 적에게 대쉬 후 베기 |
| R | 재장전 (5발) |

## 데미지 규칙
- 스나이퍼 헤드샷: 즉사 (머리 분리 연출)
- 스나이퍼 몸샷: 60 데미지 (로봇 체력 100) → 두 번째 몸샷에 사망
- 단검 대쉬 베기: 즉사 (상하 절단 연출)

## 적
- **근접 로봇 (주황)**: 달려와서 펀치 (25 데미지)
- **원거리 로봇 (빨강)**: 멈춰서 팔 캐논 충전(빨간 조준선 텔레그래프 0.7초) → 플라즈마 탄 발사 (15 데미지, 회피 가능)

## 레벨
반경 ~45m 원형 초원 아레나. 중앙에 로봇 추락 지점(크레이터, 격납고, 발전기), 사방에 엄폐용 바위·폐허 기둥.
외곽은 절벽과 나무로 둘러싸임. 적은 하늘에서 떨어지는 드롭 포드로 스폰(빛기둥 텔레그래프).
